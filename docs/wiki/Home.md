# 行矢

行矢是独立的弓弩功法内容包，命名空间为 `meridian_wayfarer`。
一书三卷，按卷学习：弓上卷「百步」、弩卷「机弩」、弓下卷「万矢」。弓下卷以前置弓上卷为条件。

正式目录已提供十式、三卷、承接与分段做功。Technique 在每段开始时将费用与已付进度原子提交，
Framework 从当前身体时刻检查整段能力并记疲劳，无须未来起始偏移字段。
单臂式随持武器手选择另一条臂，双臂式绑定六肌。

正式包只提供目录、物品标签、弓梢伤害类型及语言资源，没有 Java 类、入口或 mixin。
Framework 管理身体与费用，Technique 调度效果，Human 执行玩家射击，Threatening 执行生物射击。
