## 射程与 AI 距离

射程按箭真能飞到的最远处定：初速是目录倍率乘满弓 3.0 或弩 3.15 格/tick，拉弦臂系数按 1 计，
用宿主同一套逐 tick 弹道（重力 0.05、空气阻力 0.99、最长 240 tick）求最远水平距离，向下取整。
射手出箭点在眼下 0.1 格，目标取身体中心；箭雨落在地面，再减去落点半径 3 格。
超过 128 格的按 128 格：原版视线判定在 128 格外不成立。
拉弦臂系数随疲劳和增益在 0.25–2 之间变，实际射程跟着变。

拉空弓的五段做功均带 `training: true`，使用 Human 正式模板中六块手臂肌肉的训练参数。
每段每肌积累 270 J 待巩固负荷，完整五段为每肌 1350 J；双臂被功法动作占用时不巩固，
收势或中断释放占用后由 Framework 在休息时巩固为耐力成长，上限为 +50%。
每次拉弦分别做功，各段请求允许提前交给 Technique 排队；排队和预检不扣费。
在该段实际开始时才向 Framework 提交当前段活动，不能把前面多次拉弦的费用合并到第 4 秒，
也不能把放箭时刻直接当作拉弦开始时刻。打断、死亡、下线或取消后，未开始段不扣，已扣不退；
到时能力不足则终止后续施放，不能继续放箭后再补扣。
本目录不再使用起手 `cost.work`，真元仍在起手支付。各开始事件写入 `effects.at_millis` 与 `work`，
费用和原事件下标由 Framework 原子保存；重试不重复支付，同刻费用先于世界效果。
不向 `ActivityEffort`、`TissueCapabilities` 或 `WorkCost` 增加未来起始偏移。

迟到 tick 保留事件顺序，但在宿主当前身体时刻检查各段，不倒退身体时钟。

这些数值仍为占位，未据视觉曲线自行减少总费用。

## 承接与换兵

所有承接窗口均为前式收势后半段至收势结束后 500 ms，只省起手时间，冷却从收势结束计。

- 弓梢接连珠：400 ms 起播；连珠接回马：350 ms；连弩接横风：400 ms。
- 满月或箭雨接天地同至：1200 ms 起播；天地同至只能这样施放。
- 任一弩式接满月／连珠／弓梢：分别 400／400／300 ms 起播。
- 满月、连珠、弓梢、回马、箭雨接任一弩式：400 ms 起播。
- 拉空弓不作前式或后式，天地同至结束后不换兵承接。

宿主在新式起手时检查实际武器，不由目录直接换物。

## 方向与动画

表现 ID 为 `meridian_wayfarer:wayfarer_<式>`，宿主在武器位于副手时选择 `_off`。
已完成动画的九式撒放和弓梢打击时刻与上表一致；步伐姿势调整不改变这些服务端效果时刻。
横风主手六发偏航为 +45/+27/+9/−9/−27/−45°，正值向右；副手取反。
每发吸附半角 9°，对应自己的 18° 扇区。

箭雨按 50° 抛射，落点中心最远 123 格、半径 3 格；天地同至起手锁定 125 格内目标／落点，
三支仰射以原剪辑 5000 ms 平射为参考，预计到达晚 100 ms；仰角低于 45°或初速超过 1.1 倍时退为普通抛射。
平射带 3000 ms 盾冷却。手臂曲线从 3600 ms 开始，力量和功率峰值 1.4，
相对点为 0→0、400→1、1600→1、2400→−1、9000→−1、11000→0。
因此原剪辑 4000–5200 ms 为 1.4 倍，6000 ms 后为 0.6 倍，14600 ms 归零。
曲线显式使用 `AT_EFFECT_TIME`，到原剪辑 3600 ms 才登记；承接时仍按 1200 ms 起播偏移换算。
沉身前终止不会产生增益或虚脱，已支付真元不退。到时登记后终止仍保留剩余曲线，
迟到 tick 只登记当前值及剩余区间，不延长原到期时间。仰射估算参考平射肌力时使用
施放状态内的待登记曲线构造只读候选，实际撒放仍读取当前身体能力。

弓梢后撤两次、回马三次水平冲量均为输入方向 3 m/s，零输入向后；回马第三步另向上 6 m/s。
九式施放限速 0.4，拉空弓限速 0；所有式默认拦原版弓弩使用与左键。
